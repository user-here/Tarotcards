# 星语塔罗 · 微信小程序

一款以韦特塔罗为载体的心灵探索小程序：每日一牌、6 种牌阵占卜、78 张牌图鉴、占卜记录与收集系统。纯前端实现，无需服务器，所有数据保存在用户本地。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 每日一牌 | 每位用户每天固定一张牌（日期 + 用户随机盐生成），翻牌动画；综合/爱情/事业/财运/健康评分、幸运色、幸运数字、宜忌；连续翻牌天数 |
| 牌阵占卜 | 单牌指引、时间之流、困境突破、恋人金字塔、二选一、凯尔特十字 |
| 占卜流程 | 选方向 + 写问题 → 呼吸冥想过渡 → 洗牌 → 轻触切牌 → 滑动 78 张牌轮选牌（带惯性） → 3D 翻牌揭示 → 解读 |
| 解读 | 逐张牌义（结合所问方向）、整体能量评分、大阿卡纳 / 正逆位 / 四元素统计、综合解读、星语寄言；二选一会对比 A/B 两条路 |
| 分享 | 解读页可分享给好友，好友打开能看到同样的牌面（不包含问题原文）；首页支持分享到朋友圈 |
| 图鉴 | 5 个分类 78 张牌，正/逆位切换，爱情/事业/财富牌义，抽到过的牌会被点亮 |
| 我的 | 占卜次数、连续翻牌天数、收集进度、“与你最有缘的牌”、记录管理、入门指南、关于与声明 |

## 目录结构

```
miniprogram/
├── app.json / app.ts / app.scss      全局配置、主题变量、通用样式
├── styles/icons.scss                 内联 SVG 线性图标
├── assets/                           牌背、分享封面、星空；cards/ 22 张大阿卡纳；thumbs/ 56 张小阿卡纳缩略图
├── components/
│   ├── nav-bar/                      自定义沉浸式导航栏
│   └── cosmos/                       星空背景
├── data/                             78 张牌的牌义库、牌阵定义、类型
├── utils/                            解读引擎、每日运势、本地存储、随机数
├── pages/                            主包：首页、我的、记录、入门指南、关于
└── tarot/                            分包：提问、抽牌、解读、每日一牌、图鉴、牌详情
    ├── cards/                        56 张小阿卡纳牌面
    └── components/spread-layout/     牌阵布局与翻牌组件
```

主包约 1.5MB，`tarot` 分包约 1.7MB（单包上限 2MB）。分包页面可以引用主包图片，所以大阿卡纳放在主包，小阿卡纳放在分包。首页通过 `preloadRule` 预下载分包，进入占卜时无需等待。

## 本地运行

1. 用微信开发者工具打开本目录（`project.config.json` 中的 AppID 已配置）。
2. 工具会自动编译 TypeScript 和 SCSS。渲染引擎使用 WebView（未启用 Skyline）。
3. 类型检查：`npx -p typescript@5 tsc --noEmit -p tsconfig.json`

## 上线前检查清单

- [ ] **服务类目**：小程序后台 → 设置 → 服务类目。“占卜/算命”类内容属于审核敏感项，建议选择 **娱乐 → 休闲小游戏 / 测试** 等娱乐类目，并在描述中强调“心理探索、娱乐参考”，避免使用“算命”“预测命运”等措辞。
- [ ] **名称与简介**：小程序名称如果被占用，需要改名（同时修改首页的“星语塔罗”字样）。简介可写：“抽一张塔罗牌，听听内心的声音。仅供娱乐与自我探索。”
- [ ] **免责声明**：已在首页底部、解读页、每日运势页和“关于与声明”页中体现，请保留。
- [ ] **用户隐私保护指引**：本程序不收集任何个人信息，不调用需授权的接口（无登录、无相册、无定位），只使用本地缓存。一般无需填写，如后台提示，按“未收集”如实填写即可。
- [ ] **牌面版权**：基于 1909 年版韦特塔罗（Pamela Colman Smith 绘制，已进入公有领域，来源 Wikimedia Commons），重新着色为“金线夜幕”风格。“关于”页已注明。注意：“恋人”“星星”等牌是原版画面，含古典风格裸体形象，若审核提出异议可说明为经典公有领域艺术作品。
- [ ] **真机预览**：在开发者工具中点击“预览”，用手机扫码，重点体验牌轮滑动、翻牌动画、分享卡片。
- [ ] **上传与提审**：开发者工具 → 上传 → 小程序后台 → 版本管理 → 提交审核。

## 网页版（GitHub Pages）

`web/` 是同一套产品的网页版（Vue 3 + Vite），可以直接在浏览器里使用：

- **与小程序共用内容和逻辑**：直接引用 `miniprogram/data`（牌义、牌阵）和 `miniprogram/utils`（解读引擎、每日运势、本地存储）。`src/lib/wx-shim.ts` 用 `localStorage` 实现了 `wx.getStorageSync` 等接口，因此修改牌义或解读逻辑后，两端会同时生效。
- **素材**：构建时由 `scripts/copy-assets.mjs` 从 `miniprogram/assets` 和 `miniprogram/tarot/cards` 复制，不重复提交。
- **样式**：由小程序 SCSS 转换而来，`rpx` 换算为随屏宽缩放的 CSS 变量；桌面端显示为居中的手机宽度。
- **路由**：使用 hash 路由（`#/result?...`），适配 GitHub Pages 的静态托管。

本地开发：

```bash
cd web && npm install && npm run dev
```

推送到 `main` 分支后，`.github/workflows/pages.yml` 会自动构建并发布到 GitHub Pages。
